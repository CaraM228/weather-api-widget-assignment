# Weather Forecast Widget Assignment
A 3-day forecast widget for Calgary Alberta.

## Features
- A 3-day view of Calgary's forecast.
- Ability to toggle between Celsius and Fahrenheit.
- Responsive design for all platforms.
- Error message if API cannot be located.
- Simple layout with easy to read data.

### Resources Used
- Heroicons (icons)
- Tailwind CSS (Styling)
- WeatherAPI.com (data)
